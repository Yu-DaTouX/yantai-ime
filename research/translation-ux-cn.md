# 国内输入法「中译英 / 翻译」功能调研

调研日期：2026-11-08 · 方式：公开网页检索与抓取（官方帮助、官方更新日志、商店页、教程/评测）· 未安装、未操作任何竞品软件

## 一、结论

1. **国内输入法的翻译，主流形态是「输入框里的替换」，不是「候选窗里的解释」。** 搜狗手机版快捷翻译、百度手机版快捷翻译、微信输入法边写边译，都是把中文直接变成外文写进当前输入框，用户看到的就是最终要发出去的文字；没有一个把整句译文放进候选列表里让你挑。唯一把翻译塞进候选窗的是**百度的 `vf` 前缀模式**（译文作为候选项，数字键/空格上屏）和**QQ 拼音的「即时翻译」**（悬停候选词弹英文，点一下把中文换成英文），两者都只做**词/短语级**或前缀限定场景。
2. **PC 端几乎没有「快捷键整句翻译」这个范式。** 搜狗 PC 是一块独立的「在线翻译」面板（工具箱/状态栏图标打开，输入—点翻译—出译文）；百度 PC 是 `vf` 前缀；讯飞 PC 是语音「随声译」；QQ PC 是鼠标悬停词级释义；微信输入法 PC 版官方描述里没有翻译。也就是说，**Ctrl+T 式的"模式切换 + 底部译文行"在竞品里找不到对应物**，我们此前取消这个快捷键是有依据的。
3. **触发成本最低的两个入口是「前缀」和「工具栏按钮」**：百度 `vf` 只需在中文状态下多敲两个字母，不占系统快捷键、不需要先"进入模式"再"退出模式"；微信/搜狗的「边写边译 / 快捷翻译」是一个开关按钮，开启后**所有**中文输入都被翻译，属于"重状态"，用户必须显式关掉。
4. **离线基本不存在。** 五家里只有百度 PC 的 `vf` 被教程明确写了"需要联网"；其余要么产品名就叫"在线翻译"（搜狗），要么接了云端大模型（搜狗手机版混元 7B、微信 16 语种互译、讯飞语音翻译）。**没有一家把中译英做成端侧模型**——这正是我们的差异点，但也意味着用户对"速度"和"要不要联网"的预期是被云端产品养出来的。
5. **结果呈现上，竞品分三档**：面板（搜狗 PC）/ 候选与悬浮弹窗（百度 PC、QQ PC）/ 直接替换输入框（三家手机版）。越靠近"直接替换"，用户操作步骤越少，但越难反悔——竞品普遍没有"一键切回中文原文"的设计。

## 二、逐家情况

### 2.1 搜狗输入法

**PC 版**

- **怎么触发**：三种入口，都是"打开一个功能"而不是"按一个翻译键"。
  - 状态栏/设置菜单里加出「在线翻译」图标，点开后在面板里输入内容、选「自动检测语言」、点「翻译」（百度经验 2023-04 的分步图文：<https://jingyan.baidu.com/article/72ee561ab1e833a06038df7b.html>）。
  - 分号工具箱：官方更新日志 2017-10-13（8.7）"分号工具箱增加表情、翻译入口"（<http://pinyin.sogou.com/changelog.php>）。
  - 更晚的 AI 形态：2024-11-22（14.11）"AI 划词工具……搜索/翻译/总结"；2026-02-11（16.1c）"七大 AI 帮写服务……翻译"、"AI 光标助手：在 Word/WPS 中输入即可通过光标入口快速唤起……翻译"（同上日志）。
- **单词还是整句**：整句（面板里粘一段话翻一段话）；划词形态是选中的片段。
- **结果显示在哪**：**独立面板**，面板内有输入框和译文区，不是候选窗。教程只写到"点击翻译，翻译的内容就显示出来了"，**是否支持一键插入光标处未查到**。
- **在线还是离线**：在线（产品名即「在线翻译」；2013-11-20 的 6.8 版更新日志写"新增在线翻译、常用诗词等应用"，即作为工具箱里的一个应用上线）。
- **怎么上屏 / 能否切回**：面板与输入状态解耦，关掉面板即回到原来的中文输入；译文要不要用、怎么用由用户自己复制。**"从译文回到中文原文"未查到**（面板场景下本来就没替换过原文，所以不存在这个问题）。

**手机版**

- **怎么触发**：键盘左上角 S 图标 → 常用功能 → 快捷翻译（没有的话在工具栏里）；启用后点键盘上翻译框的"点击这里，开始翻译"（官方 FAQ：<https://shouji.sogou.com/wap/feedback/faqdetail?id=2000208>）。语音侧：长按空格说话，**上划可切换语种和翻译模式**；或点工具栏语音按钮进入"翻译"页，左侧"中英"可换语种（官方 FAQ：<https://shouji.sogou.com/wap/feedback/faqdetail?id=2000017>）。
- **单词还是整句**：整句，边打边译（"自动把你输入的中文翻译成输入到文本框中"——中国日报 2020-08-10：<https://cn.chinadaily.com.cn/a/202008/10/WS5f3117fba310a859d09dd020.html>）。
- **结果显示在哪**：**直接进输入框**，替换掉你打的中文，不是候选、不是浮层。
- **在线还是离线**：在线。iOS 商店页写明"AI翻译能力升级，接入混元7B高性能翻译模型，支持30+外语翻译中文，并提供20种语言互译"（<https://apps.apple.com/cn/app/id917670924>）。
- **怎么上屏 / 能否切回**：译文已经在输入框里，直接发送即可。官方 FAQ 只写了"点击即可启用"，**如何关闭/退出未明写**（按开关式设计推测为再点一次或回 S 菜单关闭，未验证）。**"一键回到中文原文"未查到**，官方只描述"翻译后的结果输入到文本框"。

### 2.2 微信输入法

**手机版（翻译主战场）**

- **怎么触发**：按钮开关，不是快捷键。微信聊天窗口点「微信输入法」图标 → 找到「边写边译」启动；点该图标可切目标语言，左滑看更多（教程：<https://wxb.yigujin.cn/knowledge/645.html>）。早期 iOS 1.0.5 内测版的形态是"文字输入栏下方出现一栏翻译区，输入中文后选择译为英/日/韩，并添加到输入栏"（腾讯新闻 2023-03-26：<https://news.qq.com/rain/a/20230326A04FTX00>）。官网页把"边写边译 / 实时翻译·轻松沟通"列为主打功能（<https://z.weixin.qq.com/>）；爱范儿评测提到"顶栏可以加入语音转文字、表情、边写边译等快捷方式"（<https://www.ifanr.com/app/1552354>）。
- **单词还是整句**：整句，边说/边打边译。
- **结果显示在哪**：**直接写进微信输入框**（教程原话："输入中文，就会自动在微信聊天窗口的输入框中输入对应的德语，最后点击【发送】"）。
- **在线还是离线**：在线（云端多语翻译）；官方没有在帮助页明写"必须联网"，**离线可用性未查到**。
- **怎么上屏 / 能否切回**：译文即正文，点发送。切语言列表里有"简体中文"，选它应等于停止翻译（**推测，未验证**）。**是否有"还原中文原文"未查到**。
- **范围限制**：现有教程全部以**微信聊天窗口**为例，其他 App 里能否用「边写边译」**未查到**——这更像是"微信内的输入法插件"，而不是全局输入法能力。
- **语种**：3.1.0 起 16 种（中、英、日、韩、泰、马来、越南、印尼、意、西、法、德、葡、俄、阿、土）。

**PC 版**

- **没有查到翻译功能。** 官方 Windows 商店描述只列"跨设备复制粘贴、同步词库和常用语、智能输入模式、常用语、符号配对"（<https://apps.microsoft.com/detail/xpfffp686ndrdz>）。常被误认的"电脑微信边写边译"是**微信客户端** 4.1.10 内测版的功能（聊天输入框右键 → 边写边译，<https://xinwen.bjd.com.cn/content/s6a13b12de4b03fa51a7ec4e1.html>），与输入法无关。

### 2.3 百度输入法

**PC 版（`vf` 前缀，五家里最接近"输入法内翻译"的设计）**

- **怎么触发**：中文状态下输入 **`vf`** 进入翻译模式（注意不是 `v`，`v` 是数字/日期/计算的 V 模式）（百度经验图文：<https://jingyan.baidu.com/album/92255446ac5104851648f4fe.html>）。
- **单词还是整句**：两者都行。`vfnihao` → 词的英文；`vfnizuijinhaoma` → 整句英文（同上）。
- **结果显示在哪**：**候选窗内**。教程描述"输入中文，看下面第六项之后为即时翻译的英文选项"（<https://jingyan.baidu.com/album/6dad5075cb9e6ea122e36e61.html>）。即译文作为候选行出现，和中文候选并列。
- **在线还是离线**：**在线**，教程明确"即时翻译模式需要联网""断网后不能翻译了"（同上）。
- **怎么上屏 / 能否切回**：数字键直接选英文上屏；或按空格显示当前中文的译文、再按空格上屏（同上）。**退出 `vf` 的方式未查到**；`vf` 是可删前缀，按常理退格删掉即回普通拼音，但未见官方说明，未验证。
- **补充**：PC 端还有独立的「百度翻译桌面端」是另一个产品，不要和输入法混谈。

**手机版**

- **怎么触发**：点键盘左上角「du」图标 →「快捷翻译」→ 选「自动」并勾选语种（网易号教程摘要：<https://www.163.com/dy/article/JPB2EFUN0516UGI2.html>；正文被站点拦截，仅取到检索摘要）。语音侧：长按空格进入语音界面，说中文出外文（同上摘要；媒体稿：<https://m.ikanchai.com/pcarticle/378314>）。
- **单词还是整句**：整句（文本翻译 + 语音翻译 + 扫描翻译三种形态）。
- **结果显示在哪**：**未查到**明确的落点描述；同代产品的通行做法是写在输入条/输入框，但百度这条没有可靠来源，不臆测。
- **在线还是离线**：在线（28 种语言互译，云端）。
- **怎么上屏 / 能否切回**：**未查到**。
- **语种**：百科词条的版本记录（转述官方更新说明）称"文本翻译支持 28 种语言互译；语音翻译说中文出外语，支持中译英/日/韩"（百度百科「百度输入法」条目 v7.5 段：<https://baike.baidu.com/item/百度输入法/3457287>）。

### 2.4 讯飞输入法

**手机版**

- **怎么触发**：以**语音**为主。语音输入界面上方切到「随声译」，说完中文直接出外文（少数派评测：<https://sspai.com/post/40844>）。官方帮助写"随声译：说话随声翻译，包括中译英、英译中、中译韩、韩译中、中译日、日译中六种翻译"（<https://srf.xunfei.cn/help/>）。
- **单词还是整句**：整句（一句话说完出整句译文）。
- **结果显示在哪**：**直接进输入框**（语音转写+翻译的结果就是上屏文字）；官方没写中间是否另设译文条。
- **在线还是离线**：语音识别本身支持离线，但翻译需要云端；官方未把"随声译可离线"写进帮助，**按在线理解，未验证**。
- **怎么上屏 / 能否切回**：说完松开即上屏；在语音面板切回"普通话"等普通识别模式即回到中文。**"译文还原中文"未查到**。
- **文字输入侧**：官网首页把「快捷翻译」列为功能之一（<https://srf.xunfei.cn/>），App Store 描述写「AI翻译：语音文字实时翻译」（<https://apps.apple.com/cn/app/id1582446193>），但**具体入口、结果位置、上屏方式均未查到**（官方帮助页只详细写了随声译）。
- **语种**：官方帮助为 6 种（中英、中韩、中日双向）；同一页的简介另提"语音实时翻译功能，支持中文与英、日、韩、俄四国语言的语音即时互译"。

**PC 版**

- **怎么触发**：语音「随声译」，在语音设置里打开（2020 年评测：<https://zhuanlan.zhihu.com/p/326362907>，称支持 9 种语言与中文即时互译）。
- **单词/整句、结果位置、上屏**：整句，语音转写后直接进光标处。该来源为 2020 年文章，**当前 3.0 版是否保留、语种是否变化未查到**。
- **在线/离线**：在线。

### 2.5 QQ 输入法

**PC 版（词级，"即时翻译"）**

- **怎么触发**：把鼠标移到候选词上 → 右键 →「开启字词翻译」；开启后输入框左上角出现「A」图标，之后**鼠标悬停候选词**就弹出英文释义（官方帮助：<https://skin.qq.pinyin.cn/help/pinyin05.html>）。不是快捷键、不是前缀。
- **单词还是整句**：**词/字级**。官方定位是"帮助您在中文输入过程中，快速查询中文字词对应的英文解释"。
- **结果显示在哪**：候选词旁的**弹窗**里，一列英文释义（例：输入 `shi`，悬停「事」，弹窗给 affair 等）。
- **在线还是离线**：**未查到**。同页的"拼音小字典英汉互译"需要"在线安装英汉词库"，可推测即时翻译同样依赖在线词库，但官方没写。
- **怎么上屏 / 能否切回**：**点弹窗里的英文选项，直接把英文输出**（官方原话："输出 affair"）；中文候选没有被改掉，继续打字即可。关闭入口应由同一个右键菜单控制，但官方只写了"开启"，**关闭方式未查到**。
- **版本时效**：这段帮助写的是"QQ拼音 4.2 版本"，页面版权停在 2014 年；现行 6.7（2026-06-24）是否仍保留该功能**未查到**。

**手机版**

- **怎么触发**：工具栏里的「快捷翻译」（可在"设置 → 键盘设置 → 自定义工具栏"里显示/隐藏，百度经验：<https://jingyan.baidu.com/article/22a299b51d17d5df19376afb.html>）。
- **单词还是整句**：整句（"中英、中日、中韩实时互译，跨国聊天无压力"——腾讯应用宝官方简介：<https://sj.qq.com/appdetail/com.tencent.qqpinyin>）。
- **结果显示在哪 / 怎么上屏 / 能否切回 / 在线离线**：**均未查到**（除"实时互译"外没有更细的官方说明）。

## 四、值得借鉴的 2–3 种做法

**1）前缀式翻译（百度 `vf`）：把"进入翻译"压缩成两个字母，不抢任何系统快捷键。**
它同时解决了三件事：不占用 Ctrl+T 这类宿主/系统热键（浏览器 Ctrl+T 照常开标签）；不需要"先进入模式再退出模式"的两段式状态机（`vf` 删掉就没了）；译文和中文候选在**同一个候选窗**里并列，用户用同一套选词肌肉记忆（数字键/空格）完成上屏，不存在"两套 UI 两套按键"。
对我们的意义：我们只有一个本地 zh-en 模型，最自然的映射就是"在组字中按某个前缀/键把当前整句送进翻译，译文作为**一条候选**出现，选中即上屏英文，不选则继续选中文"。这比底部常驻英文行更省空间、也不需要新增按键语义。

**2）输入框内替换（搜狗/微信/百度手机）：不产生第二种"结果界面"。**
三家的共同点是译文直接落在光标处，用户看到的就是要发出去的东西，没有"译文条—确认—上屏"这一步。代价是**不可逆**：这五家里**都没有查到**"一键切回中文原文"的设计，用户只能删掉重打。
对我们的意义：如果走"整句翻译"，至少要做到竞品没做的两件事——上屏后保留一次撤销/回退（或原文留在草稿里可恢复），以及明确"我是在翻译，不是在改写输入"。竞品用"开关常亮"表达状态（微信的图标、搜狗的翻译框），我们用一次性的动作 + 可撤销，能避免用户忘了自己还开着翻译。

**3）按需出现、词级兜底（QQ 即时翻译 + 搜狗 AI 划词）：翻译不该常驻。**
QQ 的英文释义只在**鼠标悬停候选**时弹出，点一下才替换；搜狗的划词翻译是"选中才翻"。两者共同避免了"每个候选下面挂一行紫色小字"这种常驻噪音——这正是我们当前 `candidate_translations` 被用户嫌弃的形态。
对我们的意义：候选级释义默认关闭或只在悬停/停顿后出现，整句翻译只在用户显式动作时发生；两套翻译合并成"一个入口、两种粒度"（悬停看词、前缀/按键看整句），而不是两条并行的流水线。

**另有一条限制值得抄：微信把翻译限定在微信聊天窗口。** 场景限定让它不必处理"在代码编辑器里翻译"这类边界，也天然解释了"为什么只翻整句不翻词"。我们做全局输入法不能这么限定，但可以用同样的思路给出**明确的可翻译场景判断**（例如只在检测到成句、或以标点结尾时才把译文放进候选），减少误触发。
