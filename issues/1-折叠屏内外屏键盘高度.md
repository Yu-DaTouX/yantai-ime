标题：[Feature]: Android 折叠屏内屏和外屏各存一份键盘高度

### 在什么情况下用到

三星 Galaxy Z Fold6（外屏 sw369dp，内屏展开 sw707dp），同一台手机经常在外屏和内屏之间来回切换打字。

### 现在是怎么做的，哪里不方便

键盘高度只有一个本机设置 `platform.android.keyboard_height_adjustment`，内外屏共用。外屏窄而高，适合把键盘调高（实测和微信输入法对齐要 133%）；内屏展开后同一个百分比显得太高，挡住大半内容（内屏合适的是 106% 左右）。每次开合都要进设置重新拖滑块，或者只能在两块屏之间取一个都不太合适的折中值。

### 希望怎样改进

大屏（`KeyboardFormFactorPolicy.expanded`，即 `smallestScreenWidthDp >= 600`）单独存一份键盘高度，例如 `platform.android.keyboard_height_adjustment_large`：

- 还没存过大屏高度时沿用现在那份，老用户升级后手感不变；
- 设置页和键盘内的「键盘调整」改的是当前所在那块屏的高度，大屏时标签写「键盘高度（展开屏）」；
- `onConfigurationChanged` 里跨过 600dp 边界时切换到对应那份并重排几何，键盘开着时开合也立即生效；正在拖高度时先取消这次调整，免得把一块屏的预览存到另一块屏上。

### 其他输入法的做法（可选）

微信输入法在 Fold6 上内外屏的键盘高度是各自独立的。

### 输入法版本（可选）

Android 0.6.0（对照了 develop 96406c482，仍只有一份高度）

### 其他信息（可选）

我在 0.6.0 上做了一个实现自用：只改 Java 层 4 个文件（`AndroidLocalSettings`、`MSIMEInputService`、`KeyboardOptionsPage`、`KeyboardFragment`），约 50 行，Fold6 真机上用 `cmd device_state state 0/3` 模拟开合验证过内外屏高度互不影响、键盘开着时开合即时切换。如果方向可以，我可以按 develop 重做并补 JVM 冒烟和笔记后提 PR。
