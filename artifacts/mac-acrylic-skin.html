候选窗皮肤设计稿：macOS 亚克力

参照 macOS 简体拼音的横排候选条：首选整块填充系统蓝、白字；其余候选不加底色，序号用小号灰字；卡片是半透明亚克力，背后的窗口被模糊。下面的桌面是模拟背景，用来看出透光效果。所有尺寸和颜色都对应现有 skin.toml 能写的键，不需要改渲染代码。

周末计划上午去菜市场买菜，顺便带一束花回来。下午整理书架，把去年没看完的几本找出来。晚上约了朋友吃火锅，七点在老地方见。记得带上充电宝，还有上次借的伞。

表情输入在候选里的样子

  • 打 meiguo、zan、xiaoku 这类词时，本机 emoji 词表命中的表情插在第 2 位（预览里「美国 🇺🇸 🗽」那一行），不再排在最后。
  • 词表已随包提供，约 2.1 万条拼音到表情的对应，不联网。
  • emoji 用系统彩色字体（Segoe UI Emoji）绘制，字号比汉字大 1 号，和预览一致。

说明：这是设计稿，候选内容是示例。浏览器里的模糊效果用 CSS backdrop-filter 模拟，实际由 Windows 系统亚克力材质绘制，透光程度会随系统「透明效果」设置和背后窗口变化。颜色值参照 macOS 系统蓝（#007aff / #0a84ff）。
