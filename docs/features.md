# 功能说明

## 功能简介

- 中文输入：全拼。
- 候选窗在高亮候选下方显示一行英文释义，来自随包覆盖表和本机 english.db，可选再用本地翻译模型补查，完全离线。
- 候选混输（总开关 + 分项开关）：英文、emoji、颜文字、符号、快捷短语、日期时间；独立英文候选输入模式。
- 词库管理：全拼 / 英文查询、新增、批量导入与导出。
- 语音输入：豆包流式识别，以及 OpenAI / SiliconFlow / Groq 转写；可选文本润色。
- 悬浮工具栏、剪贴板历史。
- 输入统计（默认关闭）：只在本机记录字符数量与活跃时长，可在设置 → 统计中查看与清理。
- 快捷短语（K，可选混入候选）、日期时间（T）、U 模式（U，部件拆字反查）、Emoji（E）、颜文字（M）、符号（S）、临时英文（Y）。
- 智能标点（中文标点后按空格转英文标点，可撤回）、成对标点补全、以词定字、简繁转换。
- 两款皮肤：原装 Fluent 与亚克力 Acrylic，均支持深色 / 浅色。

## 核心功能指南

> 下面这一节与[用户文档的 Windows 指南](https://msime.app/docs/)内容重叠。指南按设置窗口的实际布局组织，更新更及时；这里保留的是按功能组织的说明。两处不一致时以指南为准。

### 输入方案

在设置 → 输入中切换中文或日文模式。中文方案包括：

- **全拼**：按完整拼音输入。
  - 全拼直接输入声母即为简拼，支持声母首字母和 zh / ch / sh 声母，也支持简拼与全拼混输，例如 `nh` → 你好、`eq` → 而且、`zhly` → 张靓颖、`nhao` → 你好；简拼候选与全拼候选同层按词频排序。
全拼能打出带拉丁字母的常用词（字母词），字母照原样敲一个键、汉字照常敲拼音：`txu` → T恤、`bchao` → B超、`aazhi` → AA制、`kalaok` → 卡拉OK。字母词默认占候选首页里最后一个普通候选的位置，普通候选照常按词频排（`zhel` 首选 这里，浙L 在首页末位）。字母词只占普通候选的位置：首选、英文、emoji、云、AI、日期时间、快捷短语和手动固定了位置的候选都留在原位，被占掉位置的普通候选往后顺延。emoji 与英文都占着首页时，字母词照样占除首选外最后一个普通候选的位置。同一次出现好几条字母词时，其余的紧跟在第一条后面。首页上除首选外没有普通候选时（每页 3 个，首页是首选、emoji 和英文），字母词排在第二页第一位。候选不满一页时，字母词占除首选外最后一个普通候选的位置。打全词里第一段字母后，三个键起还会补以它开头的更长的词（`txu` 补 T恤衫，`nabla` 补 Nabla算子；`nab` 没打全 nabla，不补，首选仍是 那边）；整句里也能组进去，例如 `maiyijiantxu` → 买一件T恤。字母词不参与调频，含字母词的整句也不会存进用户词库。i、u、v 开头的字母词（U盘）可以单独打（`upan`），但夹在句子中间时全拼切不开整串，暂时组不进整句；车牌（`ea` → 鄂A、`zhee` → 浙E）只在整串正好是它时单独出现，不补全、不组进整句，免得 `jiuzheeyang` 这类普通句子被拆成车牌。内置词条来自万象词库，带数字或符号的（3C认证、USB-C）不收；万象没有京、津、沪的车牌。自己常用的字母词可以在设置 → 词库 → 字母词里添加，见下文「词库管理」。

长词前缀补全：首选已经是 4 个字以上、覆盖整串输入的词时，候选第二位会出现词库里以它开头的最可能的更长的词，例如 `zhonghuarenmin` 的第二位是「中华人民共和国」；选中它会把整串输入一起上屏。前四个字本身不是词库里的词时（诗句、长专名），首选是整句猜的，字常常猜错，这时只按拼音找：`chuangqianmingyue` 的首选是「窗前明月」，第二位照样是「床前明月光」，`makesizhu` 补出「马克思主义」。首选本身是词库里的词时（人工智能）按它的字找，而且更严：要模型认可才补，「人工智能能」「社会主义好」这类切词残片不补；但以它开头的更长的词只有一个时总会补（「海内存知」补出「海内存知己」）。打分优先用设置页里激活的万象等语法模型（不用打开整句加成），没有时用 Trigram 模型（sc.lm），再没有就用随包的神经模型：`bujinchangjiang` 有万象时第二位是「不尽长江滚滚来」。几个模型都只看候选不多时的先后，不因为诗句、化学名在模型里概率低就不补。选过的补全会在它自己的读音下调频，下次排得更靠前；补全不能置顶或固定位置，可以删除。全拼支持。开关在「联想」设置里，最少字数在配置文件 `[association] prefix_completion_min_chars` 里调（3~8）。补得出什么取决于词库收了多少长词。

翻页按键可在设置中勾选：`-` / `=`、`,` / `.`、`Shift + Tab` / `Tab`、`Page Up` / `Page Down`；`↑` / `↓` 用于移动高亮候选项。

中英文状态可按应用分别记忆，也可全局统一。Vim 用户可[按应用启用 Esc 自动切英文](vim-mode.md)。`Ctrl + Shift + E` 可进入或退出独立的英文候选输入模式。`Ctrl + .` 切换中英文标点，`Ctrl + Shift + Space` 切换全角 / 半角。简繁输出可在设置中选择。


平时候选条**不**带英文、宽度不变，只在候选卡片最下面固定一行，显示当前高亮候选的第一条英文词义（词性小号灰字跟在后面，右侧是「Ctrl+↵ 上屏」提示）。高亮换到哪个词，这一行就跟着换；本页只要有一个候选查得到英文就保留这一行（高亮到查不到释义的词时显示灰色「—」，避免窗口跳动），整页都没有释义时才不显示；随包覆盖表里标成「-」的词（的、就、都等虚词和碎片）高亮时不显示这一行。这一行宽度等于候选条宽度，英文太长时末尾省略，上屏的仍是完整文本；横排、竖排候选窗都是最下面一行。开关是设置 → 输入 →「候选词英文行」，对应配置文件的 `[general] english_line`（默认打开）。

- `Ctrl + Enter`（`[keybindings] commit_english`，默认 `"Ctrl+Enter"`）上屏英文行显示的那个词义；当前高亮候选没有释义时这颗键什么都不做。
- `Ctrl + Shift + Enter`（`[keybindings] english_senses`，默认 `"Ctrl+Shift+Enter"`）把候选框原地换成当前高亮候选的全部英文词义清单：固定竖排，顶部一行小字「<中文原词> → 英文」，每行一条词义，词性小号灰字靠右、不上屏；宽度随最长项，上限 320 DIP，超出用省略号；最多 9 条、重复的去掉。清单里按 `Ctrl + Enter` / `Space` / `Enter` 上屏高亮那条，数字 `1`–`9` 直接选，方向键移动，`Esc` / `Backspace` 只退回原来的中文候选（候选与高亮不变）。没有释义时清单只显示一行灰字「没有英文释义」，按任意键退回。
- 键位只支持 `Ctrl` / `Ctrl + Shift` 加一个键名（如 `Ctrl+Enter`、`Ctrl+Period`），写成空字符串表示关闭。
- 释义来源按优先级：① 随包覆盖表 `assets\dictionary\zh_en_gloss.tsv`（`chinese<Tab>gloss`，约 5000 个高频词；gloss 为 `-` 表示这个词不显示英文行）；② 本机 english.db 的中译英表（含 custom_translations.txt 覆盖）；③ 已安装「整句翻译模型」时，对前两者都没有的短词（最多 6 个汉字）后台翻译、按词缓存，译好后自动补上，按键不会等它；没装模型就什么都不补。全部离线，不联网。清洗规则：按 `;` 拆词义、去掉开头的词性标签与首尾空白，句子型释义去掉句末句号，专有名词保留大小写。上屏的英文不调频、不写用户词库；高亮的词只覆盖一部分拼音时（如 `shijianguanli` 高亮「时间」），只把这一段换成英文上屏，剩下的拼音继续输入，和普通的部分上屏一致。

### 候选项调频

可以在设置中自行选定调频算法：

- **关闭**：不调整顺序。
- **一次置顶**：把触发调频的候选移到首位。
- **折半调频**：把候选移到当前名次与首位之间。
- **线性调频**：按固定步数向前移动（步长可设为 1～6）。
- **一次置前**：前五名中的候选前移一位，第五名之后的候选提到第五名。

还可设置触发频次（同一候选累计选中多少次后才调整一次，1～6）。

### preedit 显示设置

用户可以通过设置 → 外观 → 行内预编辑和设置 → 外观 → 候选窗预编辑来控制应用内的拼音串和候选框内的拼音串的显示风格以及是否显示。

行内预编辑可选「原始按键」「拼音分词」或「不显示」。候选窗预编辑可选「拼音分词」或「不显示」。两者相互独立。

### 候选混输和英文输入法模式

全拼输入中文时，可以把英文、emoji、颜文字、符号、快捷短语和日期时间直接混进候选，不用切换到对应的快捷模式。这些开关集中在设置 → 实用功能的「候选混输」里：总开关关闭后全部不混入，展开后可逐项开关，各项的设置在总开关关闭期间保留。

- **中英混输**：根据字母串补充英文候选。触发字符数可选（1～8），达到该长度后才出现英文候选项。
- **emoji 混输**：输入恰好等于某个 emoji 关键词时（`xiaolian` → 😀），最匹配的那个 emoji 插在首选之后（第 2 位），被挤的普通候选顺延；候选或每页不足两个时没有可让的位置，它和其余 emoji 一起排在末尾。其余 emoji 排在候选项列表最后，打到一半的前缀不会带出 emoji；**颜文字混输**排在末尾的 emoji 之后。区域指示符拼成的国旗 emoji（🇨🇳、🇺🇸）由候选窗随包的 Twemoji Mozilla 私有字体渲染（Windows 自带的 Segoe UI Emoji 没有国旗图案）。翻页扩展候选时，其余 emoji 与颜文字仍在列表末尾。
- **符号混输**（默认关闭）：输入恰好等于某个符号编码时加入符号，例如 `alpha` → α、`infinity` → ∞、`szq` → ①…、`xl` → α β γ…。数字读音 `ling`、`yi`～`shi` 混入序号写法（`yi` → ① ⑴ ⒈）；常用标点按读音混入（`dian` → · 、，`shuminghao` → 成对的 《》 〈〉）。只认整串精确匹配，读得成拼音的编码（`xi` → ξ）也照样混入。首个符号和字母词一样只占普通候选的位置，排在首页里最后一个普通候选的位置：打 `alpha` 时 α 在首页末位。同一次也有字母词时，首个符号紧跟在字母词之后。其余符号排在列表最后。
- **快捷短语混入候选**：见下文「实用功能快捷模式」。
- **日期时间混入候选**：输入 `rq` / `riqi` / `date`、`sj` / `shijian` / `time`、`xq` / `xingqi` / `week` 时，当前日期、时间或星期出现在首个候选之后，其余格式排在列表末尾；展开全部日期格式的「📅日期」入口默认关闭。

英文、emoji、颜文字、符号和日期时间在同一条后台线程里查询，一次输入的结果一并合进候选，候选窗只刷新一次；快捷短语在组页时同步混入。

在英文模式下，按下 `Ctrl + Shift + E` 可以切换到独立的英文输入法模式。这个模式与中英混输不同：中英混输是在拼音候选中补充英文，英文候选模式则专门按英文词库匹配当前字母串。

### 标点与以词定字

- **智能标点**（默认关闭，需在设置中开启）：中文标点状态下，输入中文标点后按空格会把它转为对应英文标点（如 `，` + 空格 → `,`），再按同一标点键可撤回；设置中可分别开关四个子项：中文标点后按空格转换（`。，！？；：、`，以及单独出现的 `“”` `‘’` `【】` `《》` `（）`）、同键转回中文（2 秒内再按同一标点键撤回）、数字后直出（数字后输入 `,` `.` `:` 直接输出英文）、字母后直出（字母后输入 `,` `.` `:` 直接输出英文）。括号引号这些成对标点只在**单独出现**时转换（需关闭「成对标点自动补全」，或输入右半符号）；自动补全产生的一对不转换，按空格只落空格。
- **成对标点自动补全**：输入左侧括号、引号等成对符号时，自动补上右侧符号，并把光标放在中间。
- **以词定字**：开启后，按 `[` 上屏当前高亮候选的第一个汉字，按 `]` 上屏最后一个汉字。
- 中文标点状态下，`\` 输入顿号 `、`，新安装时 `/` 也输入顿号（可在设置「输入 → 顿号自定义」中调整，至少保留一个，未勾选的键按原样输出），反引号输入间隔号 `·`，`Shift + 6` 输入省略号 `……`，`Shift + -` 输入破折号 `——`，`Shift + ,` / `Shift + .` 输入书名号 `《` / `》`。

### 实用功能快捷模式

均在中文状态下用 `Shift + 字母` 进入，可在设置 → 实用功能中分别开关。

| 模式 | 快捷键 | 说明 |
|---|---|---|
| 快捷短语（K） | `Shift + K` | 再输入字母编码调用短语。编码只能是英文字母。出厂不带内置短语，全部由用户自行添加；支持查询、新增、批量导入和导出。短语正文可以是多行，换行能否生效取决于目标输入框：多行编辑框会分行，单行输入框会忽略。 |
| 日期时间（T） | `Shift + T` | `rq` / `riqi` / `date` 当前日期；`sj` / `shijian` / `time` 当前时间；`xq` / `xingqi` / `week` 当前星期。全拼均可使用。 |
| U 模式（U） | `Shift + U` | 输入一个字各组成部分的拼音连写，候选出该字并反显读音。例如「晶」= 日+日+日，输入 `ririri`。空格上屏首选；数字选其他候选。 |
| Emoji（E） | `Shift + E` | 按全拼 / 简拼 / 英文关键词检索 emoji，例如 `xiaolian`、`xl`、`laugh`。 |
| 颜文字（M） | `Shift + M` | 按全拼 / 简拼 / 英文关键词检索颜文字，例如 `haixiu`、`kiss`。 |
| 符号（S） | `Shift + S` | 按分组码或符号名检索符号：`xl` / `xld` 希腊字母小写 / 大写、`sx` 数学符号、`szq` 带圈数字、`szh` 带括号数字、`lmd` 罗马数字、`jt` 箭头、`dw` 单位、`hb` 货币、`yi`～`shi` 数字 1～10 的各种写法；也可以打 typst 符号名，如 `alpha`、`infinity`、`arrowr`（arrow.r）。分组码来自 [rime-wanxiang](https://github.com/amzxyz/rime-wanxiang)，Windows 自带字体显示不了的符号已剔除，看起来与 ① ❶ 一样的 Dingbats 带圈数字（➀ ➊）也不收。 |
| 临时英文（Y） | `Shift + Y` | 之后字母按英文处理。空格上屏当前输入；数字可选英文词库单词。上屏后回到中文。 |
| 数字转中文 / 算式（V） | `Shift + V` | `V123` → 一百二十三 / 壹佰贰拾叁，`V1+2*3` → 7；数字、`.`、`+ - * /` 和括号是编码键，`Shift + 数字` 选词。全拼大小写 V 都认。 |

快捷短语除了用 `Shift + K` 按编码前缀查询，还可以混进普通候选（「快捷短语混入候选」，默认开启）：开启后，全拼下输入的编码与快捷短语的编码完全一致时，它直接出现在候选首位（固定位置的候选之后）。K 模式和混入候选在实用功能页各有开关，混入候选归在「候选混输」分组里。混入候选时，开启「快捷短语参与调频」（默认开）后，经常越过它选别的候选会让它往后退，最多退到首页最后一位。

多行短语在候选里只显示第一行，末尾的 `↵` 表示这条还有后续行；候选窗不会按行变高。短语整段连同换行一起上屏，是否真的分行由目标输入框决定——多行编辑框会分行，单行输入框会忽略，Excel 单元格里要 `Alt + Enter` 才换行。编辑时 `Enter` 换行、`Ctrl + Enter` 保存；批量文件中短语内的换行写成 `\n`、Tab 写成 `\t`，导出的文件同样使用这种写法。

剪贴板管理开启后，复制过的文本会进入剪贴板历史；关闭会立即清空记录，且只记录文本。

### 语音输入

需要网络服务。可在右键菜单中开始或停止录音，也可使用快捷键：

- `RAlt`：长按录音，松开后识别。
- `Ctrl + Win`、`RCtrl + RAlt`：同样为长按录音。
- 录音时按 `Space` 可锁定，松开长按键也不会停止。
- `Ctrl + F9`：开始 / 停止录音，也可结束已锁定的录音。
- `Esc`：取消本次录音。

ASR 提供商可选豆包（流式）、OpenAI、SiliconFlow、Groq。豆包支持数字格式化、标点预测、语义顺滑和热词表。可选文本润色（SiliconFlow / OpenAI / DeepSeek / Groq），预设包括精炼整理、忠实校对、中翻英、口语整理，以及三套自定义提示词。

上屏方式可选 TSF、SendInput 或 `Ctrl + V`。豆包流式识别还可开启 inline 预编辑：已识别文字直接显示在输入框中，松开录音键后上屏（仅 TSF 上屏时生效）。录音期间可选择暂时静音其他应用的播放声音。

### 悬浮工具栏与皮肤

- **悬浮工具栏**：可调整缩放和图标尺寸；中英文切换始终显示，其余组件（全角、标点、简繁、设置）可按需勾选。
- **皮肤**：原装 Fluent 与亚克力 Acrylic。候选窗、工具栏等界面可分别跟随全局主题，或单独指定深色 / 浅色。

### 词库

设置 → 词库可切换全拼、英文和字母词词库，支持查询、新增、编辑、删除和批量导入；也可导入纯汉字词组（例如人名），由输入法生成拼音。拼音批量文件使用 Tab 分隔“词语、编码、权重”三列，因此词语内可保留空格。用户词库可分别导出，便于备份和迁移。快捷短语的导入导出在实用功能页。

字母词（T恤、卡拉OK）在词库页的「字母词」标签下管理：按要敲的字母前缀查询（`txu`），新增时读音写成 `t'xu` 或 `T xu`，也可以留空由输入法给汉字注音。批量文件每行「词语[<Tab>读音[<Tab>权重]]」，只写词语的行自动注音；读音的写法兼容 Rime 用户词库（`T xu`）和万象（`kǎ'lā'OK`）。在拼音词库里导入或新增含英文字母的词，也会自动按字母词处理。自己加的字母词和内置的一样能单独打、能组句，升级或换词库后保留，可以单独导出；内置字母词只能查询，不能修改或删除。

### 自定义候选窗翻译

英文行的释义来自内置词库，覆盖不全或译得不准时，可以自己加一层覆盖，不需要改内置词库（随包覆盖表 zh_en_gloss.tsv 里已有的词以它为准）。

在数据目录（默认 `%LOCALAPPDATA%\metasequoiaime\`，安装时若选了别的位置就是那里）下新建 `custom_translations.txt`，每行一条，用 **Tab** 分隔源词和译文：

```
你好	hello
刚才	a moment ago; just now
serendipity	意外发现珍奇事物的本领
```

规则：源词含汉字即为中译英（英文行只用这个方向）；以 `#` 开头的行是注释；空行忽略；文件用 UTF-8 保存，带不带 BOM 都可以。同一个源词写多次时，以最后一次为准。

这份文件优先于内置词库，改完重启输入法生效。

### 服务守护

Server 启动时会同时启动 Watchdog。服务意外退出后，Watchdog 会自动拉起；短时间内反复崩溃会使用指数退避（最长约 30 秒），避免重启风暴。

开发与维护快捷键（输入法服务运行期间全局生效）：

- `Ctrl + Shift + Alt + 1`～`8`：删除当前候选窗对应位置的候选项。
- `Ctrl + Shift + Alt + C`：清除引擎缓存。
- `Ctrl + Shift + Alt + R`：重启输入法服务。
- `Ctrl + Shift + Alt + T`：立即退出输入法服务。

设置界面「外观 → 重启输入法进程」提供同样的重启操作，方便在修改界面渲染方式后立即生效。
