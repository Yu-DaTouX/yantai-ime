# 整句翻译模式

全拼中文输入时按默认 `Ctrl+T`，或点击悬浮工具栏「译」。**空闲 Ctrl+T 不拦截**，浏览器仍可开新标签；
空闲进入必须点击「译」。正在组字进入时当前高亮中文及剩余拼音的首选会转入草稿，绝不上屏。
再次切换会丢弃草稿和未选拼音；离开焦点/切换输入法也清空，不跨文档保留。

| 按键 | 行为 |
|---|---|
| 空格、数字、鼠标选词 | 中文追加草稿；选词不调频、不造词 |
| 标点 | 中文标点追加草稿，不提前上屏 |
| Backspace | 有拼音删拼音；否则删最后一个草稿词 |
| Esc | 清空草稿和拼音；已经为空则退出 |
| Enter | 上屏完整英文、清空草稿，留在模式中 |
| Shift+Enter | 上屏中文，留在模式中 |
| Ctrl+Enter | 上屏完整英文并退出 |

翻译中按 Enter 不阻塞按键线程：Server 等待当前后台结果，由 TSF 现有非阻塞提交轮询完成上屏。
约 100 ms 去抖，每次修改取消旧请求；运行超过 1 s 显示「翻译超时」，此时 Enter 保留中文并提示。
没模型/引擎/依赖 DLL 时逐词查询本机 english.db，不崩溃、不联网；点击英文行进入「输入」设置下载组件。
英文行最多两行省略，实际提交完整文本；草稿显示末尾、最新词下划线，最小内容宽 360 DIP。

设置：「快捷键」修改 `[keybindings] translate_mode = "Ctrl+T"`（空串禁用）；
「悬浮工具栏」隐藏或显示「译」按钮；「输入」下载/导入/删除「整句翻译模型」。
图片模式皮肤沿用现有按钮规则，需配置 `toolbar.buttons.translate` 的位置，或启用 button_flow；状态键是 `off`/`on`。

## 本地组件

- 安装路径：`<DataDir>/models/translate-zh-en/`；引擎、权重均不随安装包。
- 地址：<https://github.com/Yu-DaTouX/yantai-ime/releases/download/translate-model-v1/translate-zh-en-v1.zip>
- ZIP：81,237,882 字节，SHA256 `c18b9d8b9962c1a1eea9b365b70b21d5f559299f35a8a35cec517f6507fe4cf1`。
- CT2 4.8.1 + oneDNN、SentencePiece，CPU int8；没有 MKL、Python 或远程推理。
- 已加载 DLL 保留到进程退出，避免 OpenMP 卸载时访问失效 TLS；删除后重启输入法才能释放文件。
- 草稿和译文只在内存，不调频、不写用户词库，不写用户文本日志；退出后丢弃。

## 自动验证

```bash
bash E:/yantai-wt/yantai-build.sh E:/yantai-wt/translate test
bash E:/yantai-wt/yantai-build.sh E:/yantai-wt/translate tsf
```

三组测试覆盖真实控制器+词库、异步取消/超时、组件 SHA256 导入删除、按键纯策略、3000 字符译文分片；
候选几何测试覆盖 fluent/mac/acrylic、横竖排和字号 100/125/150/200% 等效缩放，并保留主线高亮留白断言。
真实后台模型冒烟输出 `Today's meeting has been rescheduled to 3 p.m.`，包含中文路径与安全退出。
这不是实际宿主/DPI 显示器的人工回归，也没有自动部署或向前台发送按键。

## 部署后人工验收（由维护者执行）

1. 用维护者的部署脚本部署 Server 与新 TSF，重开一个测试宿主，确保加载的是新 DLL。
   先在浏览器空闲状态按 Ctrl+T，应正常新建标签；键入 `nihao` 再 Ctrl+T，应进草稿，文档不能出现中文。
2. 空闲点击「译」，输入 `jintiandehuiyi` 空格、`gaidaoxiawusandian` 空格、句号；
   草稿应有两段和标点，最新词下划线，英文实时更新。Enter 只上屏完整英文，模式保持。
3. 分别验证数字/鼠标选词不上屏；有拼音退格删字母，没拼音退格整词删；Esc 第一次清空、第二次退出；
   Shift+Enter 只上屏中文；Ctrl+Enter 上屏英文并退出；Ctrl+T/工具栏退出丢弃未提交草稿。
4. 选词后立刻 Enter，不能提交上一句译文或提前落中文；快速连续改稿只显示最后一版。
   造出超两行英文后提交，文档应包含完整句子，没有省略号、截断、重复或换行键残留。
5. 没有模型时仍能进入，英文退回 english.db 并提示下载；点击英文行进入设置，在线下载或 ZIP 导入后
   确认 SHA256。删除已加载组件应提示重启，不得崩溃。超时/失败提示下 Enter 应上屏中文。
6. 模式中切换窗口/输入框、切换输入法再回来，不能恢复旧草稿或提交旧请求；浏览器空闲 Ctrl+T 继续正常。
   改键位、隐藏「译」按钮后重开设置确认持久化。不要在重要文档里测试故障。
7. 在 100%、125%、150%、200% DPI 和跨屏、深浅主题、横竖候选布局下检查草稿/英文不重叠、命中区正确；
   高亮右侧留白保持 `contentPadLeft + textPadLeft`，emoji/旗帜字体及原有普通输入不回归。
8. 在记事本、Chromium/浏览器、Office（尤其 Excel）分别走一遍；游戏/UI-less 宿主只在安全测试环境验收，
   不应弹出非游戏候选 HWND。此前未手工验证这些真实宿主行为。
